# Diseño de Interfaces Web - Proyecto Órbita 1
Aplicación web orientada a la planificación de runs y seguimiento de logros en videojuegos, permitiendo a los jugadores filtrar retos según las recompensas reales que aportan dentro del juego (objetos, armas, elementos cosméticos) y consultar guías directas sin saturación de contenidos ni vídeos innecesarios.

Este repositorio actúa como centro de documentación y base para las siguientes fases de desarrollo del módulo de Diseño de Interfaces Web.

---

## Documentación del Proyecto

El documento principal de especificación técnica y metodológica de esta fase se encuentra en:

* **[Documento BRIEF del proyecto](./BRIEF.md)**: recoge el problema validado con datos de la investigación, el alcance del MVP, los arquetipos de usuario, los criterios de éxito comprobables y las restricciones técnicas y ambientales (WSG 2.4).

---

## Ecosistema de Diseño y Entregables

El proyecto vincula la investigación, la arquitectura y los bocetos a través de los siguientes entornos:

* **Tablero de FigJam:** Contiene la hipótesis inicial, el análisis de referentes (PowerPyx y TrueAchievements), los datos de la encuesta de validación, las fichas de personas (Abraham y Alejandro), la matriz de MVP, el diagrama de flujo de usuario (*user flow*) y el árbol de contenidos (*sitemap*).
* **Figma Design (Wireframes):** Bocetos de baja fidelidad en escala de grises para escritorio y móvil (*Mobile First*), estructurados mediante componentes y plantilla común.
* **Prototipo interactivo:** Recorrido navegable del flujo principal (*happy path*) que conecta la búsqueda de títulos con la ficha de juego y la creación de una *run*.
